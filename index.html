Two Sparks. Two ways to run them.

This stack is a pair of Nvidia DGX Spark nodes (Grace CPU, GB10 GPU, Ubuntu 24.04, arm64) plus vLLM, Open WebUI, n8n, and Hermes on the personal node. The boxes can share one model, or each box can own its own model. Both layouts are on this page. There is no second URL.

A · clustered TP=2 B · isolated solo TP=1 Open WebUI × 2 n8n × 2 Hermes on node-a port 8000 stays off overlays

Why two layouts

A 122B-class model at tensor-parallel 2 uses both GPUs as one pool. One listener, one weight set, apps still isolated per node. Use it when you want maximum context and one shared brain.

Isolated solo exists because a shared head can see every prompt and couples uptime. Solo gives each node its own vLLM at TP=1 so models and restarts do not cross the copper link.

Architectures

A — Clustered

One vLLM, TP=2 over Ray on the DAC. Head on node-a :8000. Worker on node-b has no API. Typical recipe: 122B-class FP8 (often cluster_only). Supported window: 262144.

B — Isolated solo

Each node runs run-recipe.sh RECIPE --solo -d --tp 1. Cluster unit disabled on boot. Supported windows: INT4 122B-class 32768; dense 27B FP8 65536. Do not raise those values.
